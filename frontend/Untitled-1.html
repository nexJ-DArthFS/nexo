1. Visión central

¿Qué es NEXORA?

NEXORA es un concepto de asistente organizado para convertir ideas, dudas y tareas en planes claros. En este MVP no hay backend ni inteligencia artificial real: solo se presenta la estructura visual y lógica de la experiencia.

Promesa del MVP

De una idea desordenada a una ruta de acción organizada.
Principio de diseño

La página está hecha para mostrar cómo se podría sentir una primera interacción: el usuario escribe, el sistema clasifica, estructura y propone un siguiente paso.

4. Flujo del sistema

  1. Entrada: el usuario escribe una idea, una duda o una meta.
  2. Clasificación: el sistema determina si es proyecto, estudio, código, investigación o archivo.
  3. Estructuración: se separa en objetivo, componentes, riesgos y siguiente acción.
  4. Salida: el usuario recibe un plan mínimo y claro.
  5. Historial: la decisión queda registrada como avance.
