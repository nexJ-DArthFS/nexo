# Documentación de NEXORA

Esta carpeta contiene la documentación funcional, técnica y de planificación del proyecto NEXORA.

Los documentos aquí almacenados definen qué debe construir el proyecto, en qué orden se desarrollará y qué decisiones se tomarán antes de programar funciones complejas.

---

| Archivo                  | Propósito                                                            | Estado                 |
| ------------------------ | -------------------------------------------------------------------- | ---------------------- |

| `roadmap.md`             | Organiza las fases, objetivos y entregables del proyecto.            | Pendiente de completar |
| `decisiones-tecnicas.md` | Registra tecnologías, métodos y decisiones importantes del proyecto. | Pendiente de completar |

## Regla de documentación

Antes de desarrollar una función importante, esta debe estar definida en `requisitos-mvp.md`.

Antes de incorporar una tecnología, framework, servicio externo o método de seguridad, se debe registrar la decisión y su motivo en `decisiones-tecnicas.md`.

La documentación debe actualizarse cuando cambie el alcance, una función, una tecnología o una decisión relevante del proyecto.
